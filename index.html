01 / PROJECT OVERVIEW

What are we
building?

A compact, automatic water dispenser that detects a cup or hand near the outlet and switches on a low-voltage DC pump for a controlled amount of time.

The Arduino reads distance from an HC-SR04 ultrasonic sensor. When an object is detected inside the set range, the Arduino activates a MOSFET or relay driver. The driver switches the pump using a separate power supply. When the timed pour ends, the pump switches off.

01 — SENSE

Measure distance

The Arduino sends a short trigger pulse. The HC-SR04 returns an echo pulse whose duration represents the distance to the object.

02 — PROCESS

Check the threshold

The sketch converts echo time into centimetres. If the reading is valid and below the chosen threshold, the controller requests a pour.

03 — ACTUATE

Switch the pump

A driver module switches the pump's separate DC circuit. The Arduino then stops the pump after the configured run time.

05 / STEP-BY-STEP BUILD

Build it in stages.

Test each stage before moving on. Do not install water near the electronics until the dry electrical tests pass.

01
▤PLAN THE LAYOUT

Plan the physical layout

Choose a stable reservoir position, cup area, outlet location, and a dry electronics compartment. Mark where the sensor can see the cup without being splashed.

  • Keep the electronics above and away from the water path.
  • Make the reservoir removable for cleaning.
  • Leave access to the power switch and fuse.
02
UNO
PREPARE CONTROLLER

Prepare the Arduino and sensor

Mount the Uno securely. Connect the HC-SR04 VCC, GND, TRIG and ECHO pins according to the pin table. Keep wires tidy and label both ends.

  • Use D9 for TRIG and D10 for ECHO in the sample sketch.
  • Check for shorts before USB power-up.
  • Upload and test the distance-reading sketch first.
03
MOSFET
ADD PUMP DRIVER

Connect the pump driver

Connect Arduino D3 to the driver signal input. Wire the pump's external DC supply through the driver exactly as its manufacturer specifies. Use a common ground reference when required by the module.

  • Verify voltage, current and polarity ratings.
  • Use suitable flyback protection for inductive loads if not built into the module.
  • Do not connect motor current through the Arduino board.
04
WATER
ASSEMBLE WATER PATH

Install reservoir, pump and tubing

Place the pump in or beside the reservoir as its design requires. Route food-safe tubing from the pump to a secured nozzle. Add strain relief so the tube cannot pull on the pump.

  • Check all joints for leaks using water only after electronics are isolated.
  • Keep the nozzle above the cup area.
  • Never allow water to drip onto the controller or supply.
05
✓DRY TEST FIRST

Test the sensor and pump separately

With the water path empty and the pump disconnected, verify distance readings. Then test the pump driver with the correct supply and a safe, controlled setup. Confirm the pump stops reliably.

  • Test sensor detection at several distances.
  • Check the driver does not heat unexpectedly.
  • Verify a timeout / maximum run duration.
06
FINAL ASSEMBLY

Secure, seal and calibrate

Fix components inside the enclosure with splash separation. Calibrate the distance threshold and dispense duration with small test amounts. Add a physical stop switch and inspect the system before every use.

  • Use a low-voltage DC supply only.
  • Do not use mains wiring near the wet area.
  • Do not drink from a prototype until materials and hygiene are verified.

07 / SAMPLE ARDUINO SKETCH

Give it the instructions.

Starter sketch for the pin plan above. Adjust the threshold and run time after testing your actual pump and sensor.

aquasense.ino
const int trigPin = 9;
const int echoPin = 10;
const int pumpPin = 3;

const int detectionCm = 10;
const unsigned long pourTime = 1800;
const unsigned long cooldown = 2500;

unsigned long lastPour = 0;

float readDistanceCm() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(3);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // Timeout prevents waiting forever for an echo.
  unsigned long duration = pulseIn(echoPin, HIGH, 30000UL);
  if (duration == 0) return -1;

  return duration * 0.0343 / 2.0;
}

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(pumpPin, OUTPUT);
  digitalWrite(pumpPin, LOW); // Pump OFF
  Serial.begin(9600);
}

void loop() {
  float distance = readDistanceCm();
  Serial.println(distance);

  bool validReading = distance > 0;
  bool objectDetected = validReading &&
                        distance <= detectionCm;
  bool cooldownFinished =
      millis() - lastPour >= cooldown;

  if (objectDetected && cooldownFinished) {
    digitalWrite(pumpPin, HIGH); // Driver ON
    delay(pourTime);
    digitalWrite(pumpPin, LOW);  // Driver OFF
    lastPour = millis();
  }

  delay(100);
}
Before using this sketch:Confirm whether your driver is active-HIGH or active-LOW. This example assumes HIGH turns the driver on. The blocking delay is intentionally simple for a classroom prototype; a robust dispenser should use non-blocking timing, sensor filtering, a maximum continuous-run cutoff, and a manual stop control.

08 / SAFETY, TESTING & LIMITATIONS

Keep water and
electronics apart.

Electrical safety
Use a suitable low-voltage DC supply, correctly rated driver, fuse and insulated connections. Never power the pump from an Arduino pin.

Water safety
Physically separate the wet path from electronics. Add drip loops, leak checks, a stable reservoir and a splash-resistant enclosure.

Hygiene
Use food-safe water-contact materials and cleanable parts. A student prototype is not automatically safe for drinking water.

Testing
Test sensor readings, pump switching, timeout behaviour and leaks independently before combining the system.
